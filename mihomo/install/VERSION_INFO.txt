FoxOS RouterOS runtime image provenance
=======================================

Prebuilt Mihomo and MosDNS archives are not stored in this repository and are
not accepted as implicit bundle inputs. Core CI and the release workflow build
all three amd64 images from the pinned sources in Dockerfile, scan each image,
and pass the exact scanned archives to scripts/build-routeros-bundle.sh.

Mihomo
------
version: v1.19.29-foxos2
source: https://github.com/MetaCubeX/mihomo/tree/v1.19.29
source archive sha256: 1db1cd49c233b67701b596fbd8a963f418ebeca4cb497f38a0e7cd706ea4c630
builder: Go 1.26.5
runtime target: mihomo-runtime
runtime base: scratch (static binary, CA bundle, timezone data, and empty /tmp)

builder: Go 1.26.5
runtime target: mosdns-runtime
runtime base: scratch (static binary, CA bundle, timezone data, and empty /tmp)
external auto-initialization: disabled

The full RouterOS bundle is currently produced only for linux/amd64. The
RouterOS-compatible files inside the bundle retain the installer-facing names
mihomo_amd64.tar and mosdns-amd64.tar.
