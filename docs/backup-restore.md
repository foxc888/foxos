# 备份、应用与恢复

FoxOS 对 Mihomo 配置使用固定安全流程：

1. 在正式配置同一文件系统创建临时文件。
2. 文件权限设置为 `0600`。
3. 调用运行时校验器验证临时配置。
4. 将当前正式配置复制到独立备份目录。
5. 原子替换正式配置。
6. 请求 Mihomo 热重载。
7. 检查 Controller 健康状态。
8. 任一步失败时恢复备份并再次重载。

## 数据目录

- 正式配置：通过 FoxOS 设置指定的共享 mount 路径
- 快照：`/data/backups/mihomo/`
- 数据库：`/data/foxos.db`

## 保留原则

后续任务清理器按数量和时间保留快照；正在使用的回滚点不会被清理。

## RouterOS

RouterOS 写操作采用独立快照与补偿逻辑，不复用 Mihomo 文件回滚。FoxOS 只修改带 `foxos:` 标识的资源。
