# 设备静态绑定与出口策略

FoxOS 将设备策略分成两个独立步骤：

1. DHCP 静态绑定：确保设备 IP 不变化。
2. 出口策略：根据稳定 IP 选择直连、Mihomo、代理链、L2TP 或阻断。

不会在同一个请求中同时修改 DHCP 和路由，避免其中一步失败后设备失联。

## 静态绑定预览

用户保存前，FoxOS读取实时 DHCP 租约并生成计划：

- 没有租约：计划创建静态租约
- 已有动态租约：计划转换为静态租约
- 已是正确静态租约：返回空计划，不重复修改
- IP 被其他 MAC 使用：拒绝生成计划
- 地址变化：明确显示旧地址和新地址

所有 FoxOS 创建的租约都带：

`foxos:device:<device-id>`

## 出口类型

- `direct`：直连 WAN
- `mihomo-node`：指定 Mihomo 节点
- `proxy-chain`：指定代理链
- `l2tp`：RouterOS 原生 L2TP
- `blocked`：阻止联网

指定节点、代理链或 L2TP 时必须使用稳定 ID，不直接依赖可修改的显示名称。

## 应用原则

当前阶段只生成计划。后续执行器必须满足：明确确认、备份、只修改 `foxos:` 资源、逐步验证和失败补偿。
